# Sneaker Palace — Client

This project uses [Vite](https://vite.dev) + React + TypeScript, with Tailwind CSS v4.

## Available Scripts

In the project directory, you can run:

### `npm run start`

Runs the app in development mode.\
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

The page will hot-reload as you make edits.

### `npm test`

Runs the test suite once via [Vitest](https://vitest.dev).

### `npm run test:watch`

Runs the test suite in interactive watch mode.

### `npm run build`

Builds the app for production to the `dist` folder, bundled and minified via Vite.

### `npm run buildAndRun`

Builds the app for production, then serves the `dist` folder locally via `vite preview` so you can check the production build before deploying.
